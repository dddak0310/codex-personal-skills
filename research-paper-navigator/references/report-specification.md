# HTML 與 CSV 交付規格

在目前工作區的 `outputs` 建立 `research-paper-review-YYYY-MM-DD.html` 與 `research-paper-matrix-YYYY-MM-DD.csv`。日期使用執行當地日期。HTML 必須是繁體中文、自包含、響應式，不依賴外部 CDN、網路字型或遠端資源；必要的 CSS 與 JavaScript 內嵌。CSV 使用 UTF-8，內容與 HTML 矩陣一致。

## HTML 內容

1. 快速導讀：以非專業人士可理解的繁體中文解釋領域、主要概念、重要理論、爭議與建議閱讀順序。
2. 摘要儀表板：總筆數、各篩選類別、全文／摘要／書目／失敗數、已深讀數與核心數。
3. 文獻比較矩陣：可排序或篩選，至少含編號、論文、年份、期刊、Q 級、Q 級來源與年份、全文可用狀態、主題契合度、方法品質、文獻角色、主要發現、重要限制、建議等級。
4. 核心文獻卡片：依必讀核心、重要補充、反方或衝突證據、方法參考、暫不採用分區，顯示入選理由、支持論點與限制。
5. 主題式綜整：按主題呈現共識、矛盾、演變與研究缺口，不逐篇流水帳。
6. 研究建議：研究定位、已有充分支持的論點、證據不足處、下一輪關鍵字與文獻類型。
7. 評分說明：說明各分項如何判斷，以及摘要限定、Q 級系統與年份規則。
8. 來源與限制：列出來源類型、查核日期、閱讀範圍、失敗／未處理／資料不足數量，以及所有重要不確定性。

## 可追溯性與驗證

所有核心推薦必須連回矩陣中的分項理由與證據來源。逐項檢查：HTML 可由瀏覽器正常開啟；行動與桌面寬度可讀；篩選與排序運作；HTML 與 CSV 的文獻筆數、識別資訊、評分、角色和建議一致；沒有把摘要閱讀寫成全文閱讀；沒有缺少依據的核心推薦。
