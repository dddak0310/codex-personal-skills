# 實作與驗證規範

## HTML 技術要求

- 產生單一、自包含的 HTML；HTML、CSS、JavaScript 與必要資料全部內嵌。
- 預設不依賴 CDN、網路字型、遠端圖片、遠端 API、fetch、XHR、WebSocket 或伺服器。
- 使用語意化 HTML。圖片有替代文字；表單控制有標籤；SVG 圖表有標題、說明或文字替代內容。
- 支援淺色與深色模式，以及至少 320px 至桌面寬度；避免重疊、裁切和不必要的水平捲動。
- 使用舒適可讀的字級，遵守 `prefers-reduced-motion`，並提供適合列印與另存 PDF 的樣式。
- 大型來源資料先聚合、降低不必要精度或移除未使用欄位，但不得改變原始數值或結論。

## 必做驗證

完成後實際檢查並修正。每項結果記為「通過／失敗／未驗證」，並簡述方法或證據；只能宣稱真正執行過的檢查。HTML 可開啟不等於沒有 JavaScript 錯誤，靜態檢視也不等於互動、鍵盤、深色、響應式或列印已驗證。

1. HTML 可正常開啟，沒有 JavaScript 錯誤。
2. 圖表實際顯示資料。逐一核對事實溯源清單中的來源值、轉換與畫面值，並檢查單位、分母、期間、缺值及四捨五入；若僅抽查，交付時說明抽查範圍，不得宣稱全部一致。
3. 所有互動控制有效，且鍵盤可操作。
4. 桌面與 320px 手機寬度均可閱讀。
5. 淺色、深色模式具足夠對比，減少動畫設定有效。
6. 列印預覽沒有嚴重破版。
7. 必要資料來源、發布日期、資料涵蓋期間、口徑、計算方式、聚合方式、限制和資料缺口均有呈現；矛盾來源分別連回各自主張，未合併成虛假的單一結論。

可用瀏覽器或既有本機測試工具進行驗證。若環境無法完成某項檢查，明確說明未驗證項目，不可宣稱已通過。
