# 視覺與敘事規範

## 選擇視覺形式

- 精確數值比較：表格或水平長條圖
- 時間變化：折線圖、面積圖或時間軸
- 類別比較：長條圖或小型多圖
- 比例結構：堆疊圖；類別很少時才考慮圓餅圖
- 分布：直方圖、箱型圖或散點圖
- 兩個數值關係：散點圖
- 多指標比較：共享尺度的小型多圖
- 階層與分類：樹狀圖
- 流程與步驟：流程圖
- 事件順序：時間軸
- 多項工作並行：泳道圖
- 已有充分證據的因果、依賴或概念關係：節點關係圖；若只有相關性，不使用因果箭頭，並清楚標為關聯
- 地理資訊：地圖，但必須有可靠地理資料
- 專案狀態：進度視圖、狀態分組或里程碑圖
- 方案選擇：比較矩陣或決策矩陣
- 大量摘要資訊：儀表板
- 教學與概念理解：互動式解說器

直接標示重要數值，減少來回對照圖例。座標軸標示名稱與單位；繁體中文的圖例、標籤與提示必須清楚。類別色彩保持一致，狀態除顏色外也用文字或圖形表示。

## 互動

僅加入能改善理解的功能，例如篩選、排序、搜尋、類別或時間切換、系列顯示、細節檢視、展開收合、節點關係檢視或投影片切換。每個控制必須實際影響內容，使用有標籤的原生控制，支援鍵盤與手機操作。靜態視覺足夠時不要強制互動。

## 視覺設計

採專業、簡潔、資訊密度適中的設計；內容優先於裝飾。保持一致的間距、字級與色彩語意，大面積背景簡潔，避免過度陰影、漸層、圓角與動畫。有品牌規範時遵循品牌；否則使用中性、高對比設計。
